# Claude Code Instructions

Read `CONTRIBUTING.md` completely before making code, narrative, documentation,
or workflow changes in this repository. It is the canonical source for the
project architecture, story constraints, commands, testing, and pull request
rules.

Apply the contributor guidance in full when working through Claude Code,
including the local diegesis and continuity review instructions. Shared project
rules belong in `CONTRIBUTING.md`; this file is only Claude's entry point to
them.

Follow the review scale in `CONTRIBUTING.md`: one outside read of the current
head by a non-author family on every agent-authored pull request, a single pass
by default, and the user-level `adversarial-review` skill at the high-risk
review boundaries. Keep agent-authored pull requests draft and never merge
unless the maintainer explicitly asks.
